Comment utiliser cet espace ? (cliquez pour lire)
  1. Quand quelqu’un vous écrit sur WhatsApp, ajoutez-le avec « + Nouvel élève ». Il commence à l’étape Prospect (intéressé, mais pas encore signé).
  2. Donnez-lui son code de dossier (ex. RI-K7P3-9QX2) : il le tape dans « Mon espace » sur le site pour suivre son dossier. Le code est créé au hasard pour que personne ne puisse deviner celui d’un autre.
  3. À chaque avancée, cliquez sur l’élève et changez son étape. Écrivez la prochaine action à faire.
  4. Quand la famille paie, cochez la tranche « Payée ». Vous pouvez changer le montant et le nombre de tranches pour chaque élève.
  5. En haut, les chiffres se calculent tout seuls : argent reçu, argent encore attendu, et ce qu’il vous reste après vos dépenses.
